About the data ​

ThermophysicalDB.jl is a reader: it does not contain any data of its own.

Credit

All the data accessed through this package are the work of others. The experimental values are published by the authors of the original articles. They are collected, standardised and distributed by the Thermodynamics Research Center (TRC) of the U.S. National Institute of Standards and Technology (NIST) as the ThermoML Archive, using the ThermoML standard developed by IUPAC and NIST/TRC. This package only downloads, reads and filters that archive.

The purpose of the package is to bring several experimental thermophysical databases under one interface. For now the only database supported is the ThermoML Archive. This page says where its data come from, what has and has not been done to them, and how to cite them.

The ThermoML Archive ​

The first database supported is the ThermoML Archive of the Thermodynamics Research Center (TRC) at the U.S. National Institute of Standards and Technology (NIST). ThermoML is an IUPAC standard in XML for storing experimental thermophysical and thermochemical property data. The archive holds the data tables of articles published in the journals that take part in the project (the Journal of Chemical & Engineering Data, the Journal of Chemical Thermodynamics, Fluid Phase Equilibria, Thermochimica Acta and the International Journal of Thermophysics).

The archive is published as a dataset with the DOI 10.18434/mds2-2422 (NIST Thermodynamics Research Center (TRC), 2020), in the form of one compressed file that contains each article as an XML and a JSON file. This package downloads that file to your computer, checks it against the SHA-256 digest published by NIST, and reads the JSON files.

The snapshot this version was developed against

Version 2020-09-30 of the archive: 11 923 articles, from which the package extracts 122 481 studied systems. The package asks NIST for the latest release each time you use it (see Downloads, updates and cache), so newer releases are picked up without a new version of the package.

What this package does to the data ​

StepWhat happens
DownloadThe file is fetched from NIST and verified. The package never redistributes it.
ParsingEvery property value, with its conditions, composition and uncertainty, becomes one row of a table. Values are stored exactly as published.
UnitsConversions to SI or to Unitful are done on request, with exact factors. They are never applied silently.
UncertaintyThe published uncertainty is kept untouched; a second column restates it at   using a documented rule. See Uncertainty.
FilteringOnly the filters that you give are applied. Outlier detection is an optional, separate step, implemented in this package and not endorsed by TRC/NIST; nothing is removed from the data unless you ask for it.

Experimental data, as published

The archive is a collection of published experimental results. It is not a critically evaluated database: points from different articles can disagree, some are wrong, and the same measurement may appear in more than one article. Judging the quality of a point is your task, and the tutorials show ways to do it (for instance, comparing water densities with a reference equation).

What is not included ​

  • Reaction data. The archive also contains reaction and equilibrium-constant blocks; this version of the package reads property data of pure compounds and mixtures only.

  • Systems with more than three components. The archive contains none.

  • Predicted and critically evaluated data. ThermoML can store them, but this package is built for the experimental data of the archive.

Terms of use and citation ​

The data are provided by NIST/TRC and come from published articles. Read the terms on the dataset page of NIST and the NIST statement on copyright, fair use and licensing before reusing the data in your own work. This package is an independent open-source project: it is not a product of NIST, TRC, IUPAC or the journals, and it is not sponsored or endorsed by any of them.

Permission of the publishers

NIST states that the files of the ThermoML Archive are available with permission of the journal publishers. For that reason this package does not contain, mirror or redistribute any file of the archive: every user downloads it directly from NIST, to their own computer. If you redistribute data obtained through this package, check first that you are allowed to.

Statement requested by TRC

TRC asks that works which use ThermoML Archive data include a statement of the form Data distributed through the [journal(s)] ThermoML Archive(s), naming the journals of the articles whose points were used, together with the citations listed below.

Modified data and warranty

The tables produced by this package (values in SI units, uncertainties restated at  , selections and merges) are modified forms of the published data. When you share them, say that the data were modified, state the date and the nature of the changes, and acknowledge NIST as the source, as the NIST license asks for modified data. The package is provided under the MIT license without any warranty. NIST/TRC checked the values and metadata for completeness and accuracy of representation, but did not critically evaluate them, and this package does not either. You are responsible for checking the data before using them and for following the terms of NIST and of the publishers.

When you publish results obtained with this package, please cite:

  1. The original articles of the points that you used. Every point carries the DOI of its article in the doi column, so a list of references for any selection is one line:

    julia
    unique(table(selection).doi)

  2. The ThermoML Archive as a dataset (DOI 10.18434/mds2-2422), in the form recommended on its page (NIST Thermodynamics Research Center (TRC), 2020).

  3. The ThermoML standard: (Frenkel et al., 2006).

  4. This package, with the reference given in the CITATION.cff file of the repository.

Further reading on ThermoML ​

  • (Frenkel et al., 2003): the first part of the ThermoML description, on experimental data.

  • (Chirico et al., 2003): the second part, on the way ThermoML records uncertainties.

  • The ThermoML home page of NIST/TRC, which describes the standard, the schema and the participating journals.
