Getting started ​

This page takes you from an empty Julia environment to a plotted selection of experimental points.

Installation ​

ThermophysicalDB.jl requires Julia 1.13 or later. Until the package is registered in the General registry, install it from GitHub:

julia
pkg> add https://github.com/Eduardo-BDMAlves/ThermophysicalDB.jl

To follow the plotting examples you also want a plotting package. The tutorials of this site use CairoMakie and Unitful:

julia
pkg> add CairoMakie Unitful

Start Julia with several threads

Parsing the archive for the first time runs in parallel (not necessary). julia -t auto uses every core of your machine and makes that first build noticeably faster. Later sessions load the binary cache and do not parse anything.

Build the database ​

Everything starts with one call:

julia
using ThermophysicalDB

db = database()
Dataset(2784119 measurements, 11923 references, 8526 compounds, 125 properties)

What that call does depends on what is already on your machine:

SituationWhat database() does
First use everDownloads the ThermoML Archive from NIST (about 190 MB), verifies its SHA-256 digest, parses the 11 923 articles, and writes a binary cache next to the archive. This takes a few minutes.
Later sessionsChecks whether a new version of the database was published (it warns you if so, see Updates), then loads the binary cache, which is much faster than parsing.
Same sessionReturns the object it already built, immediately.

The result is a Dataset: the whole archive in memory, organized as a few relational tables (see the data model). You rarely touch it directly; you hand it to points.

Where do the files go?

database_dir() tells you. On Windows it is %LOCALAPPDATA%\ThermophysicalDB, on macOS ~/Library/Application Support/ThermophysicalDB and on Linux ~/.local/share/ThermophysicalDB. You can move it with set_database_dir! or with the environment variable THERMOPHYSICALDB_DATA_DIR.

Select points ​

points returns a lazy selection. Every keyword is optional and they combine with AND:

julia
v = points(
    db;
    component = "ethanol", exact = true,      # pure ethanol, not mixtures that contain it
    property = "Viscosity",
    temperature = (20, 30) .+ 273.15,         # plain numbers are kelvin
)

The printed table shows the first rows. The selection itself stores only row numbers, so refining it is cheap:

julia
v2 = points(v; year = (2000, nothing))   # only articles from 2000 on
length(v), length(v2)
(220, 220)

The manual page on selecting points lists every filter, including limits written with Unitful units.

Get the columns ​

table materialises a selection as a NamedTuple of columns, one entry per field:

julia
t = table(v2)
keys(t)
(:source, :doi, :year, :components, :xkind, :property, :method, :phase, :temperature, :pressure, :x1, :x2, :x3, :value, :unit, :unc, :unc_k, :unc_level, :unc_k2)
ColumnMeaning
source, doi, yearWhere the point comes from: the database, the DOI of the article and its year.
components, xkindThe system ("ethanol + water") and what x1, x2, x3 express ("Mole fraction", …).
property, method, phaseWhat was measured, how, and in which phase.
temperature, pressureConditions, in K and kPa (kPa becomes Pa with units = :si). NaN when the source gives none.
x1, x2, x3Composition of the components, in the order of components. NaN where a component does not exist.
value, unitThe measured value and its unit.
unc, unc_k, unc_levelThe uncertainty exactly as published: value, coverage factor and level of confidence (when given).
unc_k2The expanded uncertainty restated at   (see Uncertainty).

Each column is a plain Vector, so plotting, statistics and fitting need no conversion:

julia
using Statistics
mean(t.value), extrema(t.temperature)
(0.0011123020909090911, (293.15, 303.15))

Plot it ​

julia
using CairoMakie

fig = Figure(size = (720, 420))
ax = Axis(fig[1, 1]; xlabel = "T [K]", ylabel = "η [mPa s]", title = "Viscosity of ethanol")
scatter!(ax, t.temperature, t.value .* 1e3; markersize = 10)
fig
