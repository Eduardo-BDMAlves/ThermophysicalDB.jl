Data model ​

You can use the package without ever looking at the internal layout. This page explains it because it determines what is fast, why selections cost almost nothing, and how other databases can be added later without changing the way you query.

Relational tables, stored as columns ​

A Dataset is a small relational database held entirely in memory. Instead of one object per experimental point (millions of tiny objects), each table is a struct of arrays: one plain, contiguous vector per field. Relations between tables are Int32 row numbers.

Three diagrams follow, each isolating one idea. They are drawn from the type definitions of the package, so the columns and their relations are those of the code. Every table has an implicit primary key (PK): the position of the row, an Int32 where 0 means "absent". A foreign key (FK) is such a position in another table, and UQ marks the column that identifies a row by its content, which is how rows are deduplicated.

From a value to its publication ​

A measurement knows its experiment, and an experiment knows its reference. Following the two arrows from any value gives the article it came from, with its DOI, authors and year. The source column of a reference names the database it was read from.

What a value refers to ​

A measurement points to a property, a pair of a label and a unit such as ("Mass density", "kg/m3"). An experiment points to up to three compounds, one per component of the system, and says how the amount of each is expressed (kinds).

How the columns are held ​

Each table is a struct of arrays, one contiguous vector per column, so a scan over one field reads memory in order. Repeated strings (database names, groups, methods, phases, composition kinds and the keys and texts of extra fields) are interned in seven string pools; a column that refers to a pool holds the Int32 position of the string, and comparing two strings is comparing two integers. The extra table is the one exception to the rule that a foreign key has a single target: its row refers to a row of the table named by scope.

Repeated strings (database names, methods, phases, composition kinds) are interned in string pools and referred to by number, which keeps memory small and makes comparisons integer comparisons.

Why long format ​

A mixture can have up to three components and any number of properties. In the long format, every measured value is one row that knows its experiment, its property, its conditions and its uncertainty. A system with three properties measured at the same state simply has three rows. This avoids a sparse wide table with a column per property, and it makes "all points of property X for compound Y" a single scan over two index columns.

What a selection costs ​

points first resolves your text (compound names, property labels, DOIs) to small masks over the compound, property and reference tables, which have thousands of rows rather than millions. It then scans the measurements once, testing integers and floats against those masks and the temperature and pressure limits. The result is a vector of row numbers, the DataView. Because it is only an index, refining it scans only the survivors.

One schema for many databases ​

The core columns are the ThermoML model: conditions, uncertainty and the identity of the system. Whatever another database can express in those terms is converted into them, so all sources look the same to your queries and share compounds and properties. What does not fit goes into the ExtraTable as free key–value fields attached to a reference, compound, experiment or measurement, without changing the core. Every reference records its source, so the origin of any point is always known, and points(...; source = "thermoml") restricts a query to one database.

Persistence ​

The cache is a flat dump of these arrays (see Downloads, updates and cache). Loading it rebuilds only the small lookup dictionaries; the large columns are read as they were written, which is why a later session is much faster than parsing the archive again. A schema version is stored with it, and an older cache is rebuilt automatically.
